01  Get your file from Instagram

  1. Tap the button. It opens Instagram's own download page — sign in if it asks, then tap Download or transfer information. Open Instagram's download page →
  2. Tick one box. Choose Some of your information, tick only Followers and following, pick Download to device, and tap Start export. Format: JSON is best — HTML works here too. Instagram pings you in a few minutes when the file is ready; download it.
  3. Come back here and drop the file below. That's all.
